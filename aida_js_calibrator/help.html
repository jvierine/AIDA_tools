AIDA browser star calibration workflow

This page is a compact checklist for using the browser calibrator to identify stars, fit the AIDA optical parameters, and export the result.

Basic workflow

  1. Load an all-sky PNG/JPEG image. The bundled example image is loaded automatically when the page opens.
  2. Check the UTC timestamp, latitude, and longitude. For known allsky7 filenames, the browser fills these from the filename and station id.
  3. Use brightness, contrast, and the high-pass filter so stars are easy to see. The high-pass filter is on by default.
  4. Press C to switch between image view and Stellarium-style catalog view. Press N to toggle star names.
  5. Roughly align the catalog field of view before picking stars: left-drag the image to move the 90 degree elevation point, right-drag to rotate the azimuth grid, and use the mouse wheel to scale the horizontal and vertical focal lengths together.
  6. Hold S and click an image star. The local star position is refined with an interpolated Gaussian-smoothed density estimate. Release S, then click the matching red catalog star.
  7. Repeat until at least four reliable star pairs are available. More well-spread pairs usually gives a more stable lens fit.
  8. Press F for the robust randomized Nelder-Mead fit, or G for the ordinary least-squares Levenberg-Marquardt fit.
  9. Press R to inspect fit residuals. The suggested red marker identifies the star pair furthest from the median residual pattern.
  10. Use the export buttons to copy either the fitted optpar = [...] Python array or a Python image_to_az_el(x, y) helper function.

Useful controls

  • S: enter star picking and select an image star while held.
  • C: toggle image view and Stellarium-style catalog view.
  • N: show or hide catalog star names in the current view.
  • F: fit all eight optical parameters with robust Nelder-Mead.
  • G: fit all eight optical parameters with Levenberg-Marquardt.
  • R: show or hide residual view.
  • Esc: cancel the current star selection or close the density popup.
  • Left mouse drag: move the field of view by shifting the 90 degree elevation point.
  • Right mouse drag: rotate the field of view around the 90 degree elevation point.
  • Mouse wheel: zoom the field of view by changing f1 and f2 together.

Field of view adjustment

The first alignment step is meant to be visual and approximate. Drag with the left mouse button until the catalog zenith is near the image zenith. Drag with the right mouse button to rotate the star field so bright catalog stars line up with the image orientation. Use the mouse wheel if the projected catalog field is too wide or too narrow. After the field is close, use S to create accurate star pairs and let the lens optimizer refine all eight optical parameters.

Export notes

The copied optpar array contains [f1, f2, alpha, beta, gamma, du, dv, radial_alpha]. The copied Python mapper uses the same forward model and numerically searches for the azimuth and elevation whose projected image coordinate matches the supplied pixel.

The inverse mapping is most meaningful for pixels inside the calibrated field of view and above the horizon. If the lens model is poorly constrained, add or remove star pairs and refit before exporting.
